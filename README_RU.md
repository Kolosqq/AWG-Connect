# AWG-Connect

[English](README.md) · **[Скачать 1.0.0 для Windows x64](https://github.com/Kolosqq/AWG-Connect/releases/download/v1.0.0/AWG-Connect_1.0.0_windows_x64.exe)**

Форк [AmneziaVPN](https://github.com/amnezia-vpn/amnezia-client) для Windows с **позитивным раздельным туннелированием**: выбранные приложения работают через VPN, остальные — напрямую. Сохранены оригинальный интерфейс и существующий подписанный драйвер.

## Версия 1.0.0

- Выбор `.exe` для списка **«Через VPN»**.
- Поддержка AmneziaWG и WireGuard; подключение по Premium-ключам и импорт `.conf` через привычный интерфейс.
- Запуск без консольного окна; сообщение об ошибке вместо зависания при несовместимых настройках.

Для нового режима выключите оба Kill Switch и разделение по сайтам, добавьте приложения и подключитесь. Нужны стандартные IPv4 AllowedIPs (`0.0.0.0/0`, при необходимости вместе с `::/0`). Пустой список означает прямой доступ для всех приложений. Системный DNS остаётся прямым; отдельного Kill Switch для выбранных приложений в этой версии нет.

Установщик сохраняет имена приложения и службы AmneziaVPN и заменяет существующую установку. Установщик без цифровой подписи; драйвер подписан. `1.0.0` — версия релиза форка, внутри приложения сохранён номер исходной версии `5.1.0.5`.

[Релизы и контрольные суммы](https://github.com/Kolosqq/AWG-Connect/releases) · [Сборка и проверки](docs/windows-positive-split-tunneling.md)

Выбор папок, выбор из текущих процессов и совместимость с Kill Switch запланированы для следующей беты и не входят в 1.0.0.
