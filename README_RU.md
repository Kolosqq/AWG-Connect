# AWG-Connect

[English](README.md) · **[Скачать MSI 1.1.4 для Windows x64](https://github.com/Kolosqq/AWG-Connect/releases/download/v1.1.4/AWG-Connect_1.1.4_windows_x64.msi)**

Форк AmneziaVPN для Windows с позитивным раздельным туннелированием для AmneziaWG и WireGuard. Выбранные приложения идут через VPN. Остальные приложения и системный DNS работают напрямую.

- Добавляйте EXE-файлы, папки с вложенными папками и запущенные процессы. Выбор сохраняется по пути к EXE-файлу.
- Меняйте настройки при активном VPN. После подтверждения клиент сохранит правки и переподключится.
- Обычный Kill Switch блокирует выбранные приложения при обрыве VPN. Строгий режим блокирует их и после ручного отключения, пока работает служба.

Выключите раздельное туннелирование по сайтам и используйте IPv4 AllowedIPs `0.0.0.0/0`. При пустом списке все приложения работают напрямую.

Релиз 1.1.4 основан на AmneziaVPN 5.1.0.6. Если у вас стоит MSI 1.1.1 или 1.1.2, один раз запустите MSI 1.1.4 поверх текущей версии, чтобы получить исправление обновлятора. Начиная с MSI 1.1.3, используйте **Настройки → О приложении → Проверить обновления**. При переходе со старого EXE-установщика сначала удалите старую версию, затем установите MSI. AWG-Connect проверяет обновления по отдельной подписи. При ручной установке Windows может отобразить сообщение о неизвестном издателе.
